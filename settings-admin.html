About & safety

Settings storage

This page reads and writes the following documents:

Existing document
settings/storeStatus — updates only isOpen.
New configuration documents
appSettings/business
appSettings/delivery
appSettings/payment

Security requirements

Use Firebase Authentication and Firestore Security Rules to restrict writes to authorized admins. Hiding this page or its buttons is not security. Do not allow public users to modify settings.

This page does not create users, change login credentials, or modify order/payment records.

FreshFry Admin · Settings are saved to Firestore only when you press the corresponding Save button.
